# 🌤️ Weather Widget App

This is a simple weather widget built with **React**, using the **WeatherAPI.com** to fetch real-time weather data based on:

- User's current **geolocation**
- **City name** input by the user

## 🔧 Features

- Get weather by **geolocation**
- Search weather by **city name**
- Styled with **custom CSS** and responsive layout
- Displays:
  - City and country
  - Current temperature
  - Weather condition and icon
  - Humidity and wind speed

## 🚀 Live Demo

👉 [Click here to view the live site](weather-wiget.vercel.app)

## 📦 Tech Stack

- React (with Hooks: `useState`, `useEffect`)
- WeatherAPI (free tier)
- Custom CSS
- Hosted on Vercel
